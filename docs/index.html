Do-It-Now Activities ROI Training

Pick a topic. Pick an activity. Go.

The best way to learn something is to try it yourself. So we've turned a bunch of the demos our instructors do into Do-It-Now activities, where you can try each concept out yourself in quick, bite-size pieces.

tl;dr hands-on > demos > slides

Each topic below opens a set of independent activities. They are not a tutorial and are not meant to be worked in order — every activity stands on its own and illustrates a single concept, so start anywhere and do as many or as few as you like.

If you are using these as part of an Instructor Led Training (ILT), make sure to listen to your instructor and coordinate your efforts with their direction.

Before you start

Cost

Many of these activities cost money to run. Every activity shows its cost under the title:

  • 🟢 No cost Free to run.
  • 💰 Low cost Small charges.
  • 💸 Higher cost Scans large tables; generates significant charges.

Warning: the Higher cost activities generate significant charges if run in your personal account. We assume that you are working in lab projects with lab-provided accounts. You've been warned.

Sample data

Activities note the data they need in their own setup section. Most BigQuery activities use the roi-bq-demos.bq_demo dataset; some rely on additional tables derived from it, which you can generate using the directions here.

There is also a much smaller dataset that works with the demos: roi-bq-demos.bq_demo_small. Queries are much faster against it, so it isn't as effective at illustrating query speed benefits.

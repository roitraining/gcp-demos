# 2.2 · Search the store

*Part 2 · Fill and search the store*

> [!NOTE]
> **Why you are here.** The store is full. This page sends it the four
> questions from Part 1 and shows which examples ADK would keep for each.

[store/search.py](../../store/search.py) sends the same search request as
ADK's `VertexAiExampleStore`. It also prints each match's score and whether
ADK would keep it. ADK asks for the top 10 matches and drops any that score
below 0.5.

**Step 1 — Search with an order-status question.**

**Command:**

```bash
.venv/bin/python store/search.py "Where is order 4417?"
```

**Expected output:**

```console
0.82  kept     Where is order 2210?
0.63  kept     Where's my package?
0.61  kept     Has my order 1875 shipped yet?
0.59  kept     I want a refund for order 6032.
0.55  kept     My order hasn't arrived and I'm getting worried.
0.47  dropped  What's the weather like today?
0.47  dropped  Can I get my money back? The item arrived broken.
0.40  dropped  Can you recommend a good laptop?
```

> [!IMPORTANT]
> **What it means.** The closest example is the right one, well ahead at 0.82.
> But four others also clear 0.5, including a refund example. The store ranks
> by how similar the text is, not by intent, and every question about an
> order sounds somewhat alike.

**Step 2 — Search with the other three questions.**

**Command:**

```bash
.venv/bin/python store/search.py "Where's my order?"
.venv/bin/python store/search.py "I want a refund for order 5521."
.venv/bin/python store/search.py "What's a good recipe for pancakes?"
```

**Expected output:** one block per question; most dropped rows are trimmed.

```console
0.89  kept     Where's my package?
0.85  kept     My order hasn't arrived and I'm getting worried.
0.76  kept     Has my order 1875 shipped yet?
0.69  kept     I want a refund for order 6032.
0.69  kept     Where is order 2210?
0.62  kept     Can I get my money back? The item arrived broken.
0.55  kept     What's the weather like today?

0.90  kept     I want a refund for order 6032.
0.72  kept     Can I get my money back? The item arrived broken.
0.66  kept     My order hasn't arrived and I'm getting worried.
0.64  kept     Where's my package?
0.64  kept     Where is order 2210?
0.62  kept     Has my order 1875 shipped yet?

0.56  kept     Can you recommend a good laptop?
0.49  dropped  What's the weather like today?
```

> [!IMPORTANT]
> **What it means, finding one: the right examples rank first.** For every
> question, the top match teaches the reply the store wants.
>
> **What it means, finding two: the cutoff keeps a lot.** "Where's my order?"
> keeps seven of eight examples; the pancake question keeps one. The agent
> will see every kept example, and has to follow the closest. Part 3 checks
> whether it does.

> [!WARNING]
> About one search in six fails with `500 Internal error encountered`. Run the
> command again. See [Why do some searches fail?](#why-do-some-searches-fail)

Part 3 attaches the store to the agent and asks the same four questions.

## Deep dives

### Why do the scores bunch together?

The embedding model places text by overall meaning. Short questions about an
order share most of their meaning, so they score 0.55 to 0.9 against each
other. The pancake question shares little with any example, and only the
other off-topic request clears 0.5. A larger store with more varied examples
spreads the scores further apart. ADK's 0.5 cutoff and top 10 are fixed in
`google/adk/examples/vertex_ai_example_store.py`; you can't change them
without writing your own provider.

### Why do some searches fail?

In the runs for this tutorial, 5 of 30 back-to-back searches returned
`500 Internal error encountered`; the same request succeeded on retry. The
cause is on the service side. ADK does not retry the search, so in Part 3 a
failed search fails the whole turn.

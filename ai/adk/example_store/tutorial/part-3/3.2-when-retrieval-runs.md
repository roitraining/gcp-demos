# 3.2 · When retrieval runs

*Part 3 · Attach the store to the agent*

> [!NOTE]
> **Why you are here.** In 3.1 the order question logged two example lists.
> This page explains when ADK searches and what it searches with, then
> deletes the store.

ADK rebuilds the model request from scratch for every model call, and
`ExampleTool` searches the store each time. A turn that uses a tool makes two
model calls, so it searches twice. Both searches use the same text: the
user's message for that turn
(`google/adk/tools/example_tool.py`, `process_llm_request`).

**Step 1 — Hold a two-turn conversation.**

Without a query, `adk run` keeps the session open. Type `Where's my order?`,
then `4417` when the agent asks, then `exit`.

**Command:**

```bash
.venv/bin/adk run agents/with_examples
```

**Expected output:** trimmed to the agent's lines.

```console
[user]: Where's my order?
[examples] 7 in this request
[examples]   Where's my package?
[examples]   My order hasn't arrived and I'm getting worried.
[examples]   Has my order 1875 shipped yet?
[examples]   I want a refund for order 6032.
[examples]   Where is order 2210?
[examples]   Can I get my money back? The item arrived broken.
[examples]   What's the weather like today?
[order_support]: Which order? Send me the four-digit order number.
[user]: 4417
[examples] 5 in this request
[examples]   Has my order 1875 shipped yet?
[examples]   Where is order 2210?
[examples]   What's the weather like today?
[examples]   Where's my package?
[examples]   I want a refund for order 6032.
[examples] 5 in this request
...
[order_support]: Order 4417: shipped, arrives Tuesday.
```

> [!IMPORTANT]
> **What it means.** The second turn searched with `4417` alone, not the
> conversation, and got a different list, including the weather example.
> The reply was still right: the order examples ranked first, and the model
> had the earlier turns in its history.

**Step 2 — Search with the bare order ID.**

**Command:**

```bash
.venv/bin/python store/search.py "4417"
```

**Expected output:**

```console
0.57  kept     Has my order 1875 shipped yet?
0.57  kept     Where is order 2210?
0.54  kept     What's the weather like today?
0.53  kept     Where's my package?
0.50  kept     I want a refund for order 6032.
0.49  dropped  My order hasn't arrived and I'm getting worried.
0.49  dropped  Can you recommend a good laptop?
0.48  dropped  Can I get my money back? The item arrived broken.
```

> [!IMPORTANT]
> **What it means.** Every score sits near the 0.5 cutoff, so which examples
> clear it is close to chance. A short follow-up message makes a poor search
> query. See [Can retrieval use the whole conversation?](#can-retrieval-use-the-whole-conversation)

**Step 3 — Delete the store.**

The store and its examples stay in your project until you delete them.

**Command:**

```bash
.venv/bin/python store/delete_store.py
```

**Expected output:** your IDs differ.

```console

ExampleStore deleted. . Resource name: projects/240659336105/locations/us-central1/exampleStores/1983052783577726976
```

Remove the `EXAMPLE_STORE_NAME` value from `.env`; the `with_examples` agent
won't load without a live store. The [Reference](../reference.md) collects the
gotchas from every page.

## Deep dives

### Can retrieval use the whole conversation?

Not with ADK's `VertexAiExampleStore`. It sends only the turn's user message,
and the store's only key method, `last_entry`, uses only the last entry
anyway. A provider can't fix this, because `ExampleTool` hands it only that
message. Searching on more context means writing your own tool that reads
the session and builds the query from recent turns.

### Does the search slow the turn down?

Yes. `get_examples` is a blocking network call inside ADK's async flow. In
these runs the first search took about 3 seconds and later ones under 1
second, and a tool-using turn pays for two.

### Do examples affect context caching?

Yes. The examples are part of the system instruction, so when two calls
retrieve different examples, the instruction differs and a cached prefix no
longer matches.

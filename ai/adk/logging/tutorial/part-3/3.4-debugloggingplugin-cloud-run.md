# 3.4 · DebugLoggingPlugin on Cloud Run

*Part 3 · Plugins*

> [!TIP]
> **Optional. Why you are here.** You would not run `DebugLoggingPlugin` on Cloud
> Run in practice, but doing it once teaches a lesson about file-writing tools
> in ephemeral containers.

A Cloud Run Job's disk is discarded when the execution ends, so a file at
`/app/adk_debug.yaml` vanishes with the container. Cloud Run can mount a Cloud
Storage bucket as a volume instead, and example 04 already reads its output path
from `DEBUG_OUTPUT`.

**👉 Do this.** Deploy with a bucket mounted, then read the file back.

**Command:**

```bash
MOUNT=1 SCRIPT=examples/04_debug_plugin.py ./deploy/deploy_plugin_job.sh
gcloud storage cat "gs://$BUCKET/adk_debug.yaml" | head -40
```

With `MOUNT=1` the deploy script mounts `$BUCKET` at `/mnt/out` and sets
`DEBUG_OUTPUT=/mnt/out/adk_debug.yaml` on the Job.

**Expected output** — the same YAML document as 3.3, read back from the bucket,
with the full `entry_type` sequence intact. Cloud Logging has one more line, the
plugin's own warning about the file it wrote:

```console
WARNING - google_adk.google.adk.plugins.debug_logging_plugin - Debug output file /mnt/out/adk_debug.yaml is readable beyond its owner and holds whole prompts and responses; restrict it to mode 600.
```

> [!IMPORTANT]
> **What it means.** The plugin behaved as on your laptop; only the disk changed.
> The Cloud Storage FUSE mount reports a mode wider than `0600`, so the plugin
> says so, through `logging`, on stderr. The capture now lives in a bucket and
> still holds full prompts, so bucket IAM is your new `0600`. And it is still a
> debugging capture. If you run it routinely in the cloud, you want Part 4's
> structured plugin instead.

> [!TIP]
> If you need the capture once and do not want a bucket, have the script `cat`
> the file to stdout at the end. It lands in Cloud Logging as one large text
> payload, at the cost of the "file, not stream" property that made the plugin
> worth using.

Tear down when you are done.

**Command:**

```bash
gcloud run jobs delete adk-debug-plugin-job --project="$PROJECT_ID" --region="$REGION" --quiet
```

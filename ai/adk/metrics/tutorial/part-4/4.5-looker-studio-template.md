# 4.5 · The Looker Studio template

*Part 4 · Consume — rows in BigQuery*

> [!NOTE]
> **Why you are here.** The last three pages answered questions with SQL and the
> SDK. A ready-made Looker Studio template puts the same answers on charts, so a
> teammate without SQL can read them. It needs only the `agent_events` table you
> already have.

The template is a 37-chart report that binds to one BigQuery table. It is a
browser workflow, so this page has no captured console output; you follow the
steps in Looker Studio and confirm the charts fill with your data.

**Step 1 — Open the template and make a copy.**

Open the template link from the BigQuery Agent Analytics docs
(`dashboard/looker_studio/README.md` in the SDK repo). In the top-right menu,
choose **Make a copy**. Looker Studio prompts you to pick a new data source for
the copy.

**Step 2 — Point the copy at your table.**

When prompted for the data source, choose **BigQuery**, then select your project,
the `agent_analytics` dataset, and the `agent_events` table. Confirm the copy. The
template's fields map to the table's columns, so no manual field mapping is
needed.

**Step 3 — Read the charts.**

The report groups the 37 charts into the same questions Part 4 answered with
queries:

| Chart group | What it shows | Query it mirrors |
|---|---|---|
| Volume and turns | Turns and events over time | [4.1](4.1-one-line-one-table.md) count by event type |
| Tokens and cost | Tokens per call and per session, cache hit rate | [4.2](4.2-tokens-latency-cache-per-call.md), [4.3](4.3-cost-per-session-and-user.md) |
| Latency | TTFT and total latency distributions | [4.2](4.2-tokens-latency-cache-per-call.md) |
| Errors | Tool and invocation error rates | [4.4](4.4-the-sdk.md) evaluator |

> [!IMPORTANT]
> **What it means.** The charts read the same rows your queries did, so a session
> that topped the SQL ranking tops the chart too. The template is a presentation
> layer over `agent_events`, not a separate store; it adds no data and no cost
> beyond the query volume Looker Studio runs.

> [!TIP]
> Share the report, not the dataset. A viewer of the Looker Studio report sees the
> charts without direct access to the `content` column, which keeps the privacy
> boundary from [4.3](4.3-cost-per-session-and-user.md) intact.

[4.6](4.6-metrics-or-rows.md) closes the part by setting metrics and rows side by
side, so you know which store to reach for.

# 1.2 · Reading a histogram

*Part 1 · What a metric is*

> [!NOTE]
> **Why you are here.** You have seven fields on a datapoint. This page turns
> `count` and `sum` into two answers about what one turn cost, and corrects the
> most common misconception about token metrics.

No new command: reuse the `baseline` output from
[1.1](1.1-your-first-datapoint.md). A histogram gives you two numbers per series
before you touch the buckets: `count`, how many values were recorded, and `sum`,
those values added up.

**👉 Read the token and call figures.**

**Expected output:** the relevant lines from the 1.1 capture.

```console
gen_ai.client.token.usage (input)     count=2  sum=714 tokens
gen_ai.client.token.usage (output)    count=2  sum=137 tokens
gen_ai.invoke_agent.inference_calls   count=1  sum=2
gen_ai.invoke_agent.tool_calls        count=1  sum=1
```

> [!IMPORTANT]
> **What it means, finding one: a token metric is not a counter you sum.** On
> `gen_ai.client.token.usage`, `sum` is the tokens (714 input) and `count` is the
> model calls that reported them (2). Divide and you get tokens per call. Reach
> for `count` as your request denominator and you would be counting model calls,
> not turns.

> [!IMPORTANT]
> **What it means, finding two: one turn made two model calls.**
> `inference_calls` has `sum=2` for a single invocation (`count=1`). The turn ran
> the model once to decide to call `get_weather`, then again to phrase the answer
> from the tool result. `tool_calls` `sum=1` confirms the one tool call in
> between.

Each metric answers a different operator question. Keep this mapping in view for
the rest of the tutorial:

| Metric | `count` is | `sum` is | Answers |
|---|---|---|---|
| `gen_ai.invoke_agent.duration` | turns | total turn seconds | How slow is a turn? |
| `gen_ai.client.operation.duration` | model calls | total model seconds | How slow is the model? |
| `gen_ai.execute_tool.duration` | tool calls | total tool seconds | How slow is a tool? |
| `gen_ai.client.token.usage` | model calls | tokens | How many tokens per call? |
| `gen_ai.invoke_agent.inference_calls` | turns | model calls | How many model calls per turn? |
| `gen_ai.invoke_agent.tool_calls` | turns | tool calls | How many tool calls per turn? |

The buckets, which you saw in 1.1, are what let you ask for a p95 later in
Part 3; `count` and `sum` alone give you totals and averages.

# 1.4 · The experimental family

*Part 1 · What a metric is*

> [!NOTE]
> **Why you are here.** The six metrics so far measure each model call. A
> separate family sums tokens over the whole turn, but it is off by default. This
> page turns it on and shows why the name warns you.

The `baseline` scenario again, one London turn, but with one environment
variable set. `adk.experimental.*` metrics stay silent unless
`ADK_EXPERIMENTAL_TELEMETRY` is set (`telemetry/_instrumentation.py:289`).

**👉 Do this.**

**Command:**

```bash
ADK_EXPERIMENTAL_TELEMETRY=true .venv/bin/python examples/01_console_metrics.py
```

**Expected output:** the six framework names from
[1.1](1.1-your-first-datapoint.md), plus six new ones.

```console
adk.experimental.invoke_agent.input_tokens
adk.experimental.invoke_agent.output_tokens
adk.experimental.invoke_agent.total_tokens
adk.experimental.invoke_agent.cache_read.input_tokens
adk.experimental.invoke_agent.reasoning.output_tokens
adk.experimental.invoke_agent.tool.input_tokens
```

> [!IMPORTANT]
> **What it means.** These sum tokens over the whole invocation, not per model
> call. Where `gen_ai.client.token.usage` records once per call (twice a turn
> here), `adk.experimental.invoke_agent.total_tokens` records once per turn, so
> its `sum` is the turn's total and its `count` is the turns. It also breaks
> tokens out by source: cache reads, reasoning output, and tool input each get
> their own name.

> [!WARNING]
> The name says `experimental` for a reason: these are ADK's own instruments,
> not the OpenTelemetry GenAI standard, and their names or gates can change
> between versions. Do not build an alert on them.

Run the same command without the variable and all six experimental names vanish;
only the framework six remain. The gate is a plain environment check, so nothing
downstream sees these metrics unless you opt in.

[1.5](1.5-workflow-grain-metrics.md) is the one page with a second agent, where a
seventh framework metric can finally appear.

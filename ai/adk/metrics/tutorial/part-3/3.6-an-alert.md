# 3.6 · An alert

*Part 3 · Consume: signals from histograms*

> [!NOTE]
> **Why you are here.** Scenario `unknown-city`: would this have opened an
> incident? This page turns the tool error ratio from 3.3 into an alert policy,
> then fails enough lookups to open a real incident.

The signal is the tool error ratio from [queries/errors.promql](../../queries/errors.promql):
failed tool calls over all tool calls. The policy fires when that ratio stays
above 20% for one minute. It has no notification channel, so it opens an
incident without notifying anyone.

**Step 1 — Restart the server under this page's name.** In the server terminal,
stop the server with `Ctrl+C` and start it again as `adk-metrics-3-6`, the `job`
the policy's query filters on.

**Command:**

```bash
source env.sh
export OTEL_SERVICE_NAME=adk-metrics-3-6
.venv/bin/adk web --otel_to_cloud ./
```

**Step 2 — Create the alert policy.** Run it in the second terminal. The config is
[queries/alert-policy.json](../../queries/alert-policy.json): a PromQL condition
on the tool error ratio over a 1-minute window, threshold 0.2, duration 1 minute,
evaluated every 30 seconds. The short hold keeps this page short; a production
policy should hold 5 minutes or more, so one bad minute does not open an
incident. `POLICY_ID` keeps the new policy's name for the teardown.

**Command:**

```bash
source env.sh
export POLICY_ID=$(gcloud monitoring policies create \
  --project="$PROJECT_ID" \
  --policy-from-file=queries/alert-policy.json \
  --format='value(name)')
echo "$POLICY_ID"
```

**Expected output:** the policy's resource name, with your project number and a
generated id.

```console
projects/jwd-dev-5/alertPolicies/16688615681849436857
```

**Step 3 — Trigger it.** Fire `unknown-city` long enough to hold the ratio above
20% for the one-minute duration. The load takes about 2.5 minutes.

**Command:**

```bash
load/turns.sh unknown-city 40
```

**Expected output** (turns 4 to 37 trimmed):

```console
unknown-city    turn   1  http=200  3.65s
unknown-city    turn   2  http=200  3.06s
unknown-city    turn   3  http=200  3.09s
unknown-city    turn  38  http=200  3.17s
unknown-city    turn  39  http=200  2.89s
unknown-city    turn  40  http=200  2.44s
waiting 10s for the final export interval...
good to go — the series are in Cloud Monitoring
```

**Step 4 — Read the incident.** The incident opened about 4 minutes after the
policy was created, about 2 minutes after the load ended; if the list is empty,
wait a minute and check again (it can take several minutes). List the open alerts in the project:

**Command:**

```bash
curl -s -G \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  --data-urlencode 'filter=state="OPEN"' \
  "https://monitoring.googleapis.com/v3/projects/$PROJECT_ID/alerts"
```

**Expected output** (indented, and trimmed to the fields that identify the incident):

```console
{
  "alerts": [
    {
      "name": "projects/jwd-dev-5/alerts/0.oddygi1xkc9e",
      "state": "OPEN",
      "openTime": "2026-10-03T10:03:20Z",
      "metric": {
        "labels": { "value": "0.5228577240950232" },
        "type": "prometheus.googleapis.com/gen_ai.execute_tool.duration/histogram"
      },
      "policy": {
        "name": "projects/jwd-dev-5/alertPolicies/16688615681849436857",
        "displayName": "ADK tool error ratio > 20% for 1m (tutorial 3.6)"
      }
    }
  ],
  "totalSize": 1
}
```

In the Console, the same incident is under **Monitoring → Alerting → Incidents**.

> [!IMPORTANT]
> **What it means.** The same ratio you read once by hand in 3.3 now watches
> itself and opens an incident when it breaches. Note what it does not know: it
> fires on any failing dependency, including turns the agent recovers from. The
> Atlantis users got no weather, but neither this ratio nor the invocation ratio
> says whether the task was done. 3.7 measures that.

**Step 5 — Tear down.** Delete the policy so it stops evaluating.

**Command:**

```bash
gcloud monitoring policies delete "$POLICY_ID" \
  --project="$PROJECT_ID" \
  --quiet
```

**Expected output:**

```console
Deleted policy [16688615681849436857].
```

3.7 measures the task, not the tool.

--- RUNG "recorded": no span processor -> no provider -> all-zeros trace id ---
With no TracerProvider installed, trace.get_current_span():
  trace_id = 00000000000000000000000000000000, is_recording() = False
So a server that forgets the span processor returns an all-zeros trace id; nothing
is recorded (setup.py:87 installs a provider only if span_processors is nonempty).

=== KEY 2.2 FACT (feeds 3.4): TWO trace ids per request, and they DIFFER ===
Same /chat POST (matched by requestUrl .../chat in the run.googleapis.com request log):
  ADK spans' trace id           (from /chat body + Trace v1) = 0000cb104b9c2e8d4039729a40d46eb0
  Cloud Run request-log `trace` (run.googleapis.com/requests) = 18cb1a68232775b83979db6b5bf7fcca
        (full field: projects/jwd-dev-3/traces/18cb1a68232775b83979db6b5bf7fcca)
DIFFER? YES. The Cloud Run ingress log carries Cloud Run's OWN trace id; ADK
starts a fresh trace inside the process because it does not read the inbound
X-Cloud-Trace-Context / traceparent header. Two trace ids name the one HTTP
request — the pair page 3.4 later merges via propagation.

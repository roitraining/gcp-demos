--- Tooling notes ---
trace/list_traces.sh is broken: `curl ... | python3 - <<'PY'` gives python the
heredoc as stdin, so json.load(sys.stdin) reads the script's own EOF and raises
JSONDecodeError for every call. The page uses a direct curl to the v1 list instead.
Parallel agents on the same project hit the v1 "Read requests (free) per minute"
quota (429 RESOURCE_EXHAUSTED); a 429 makes `grep traceId` print nothing. Retry.
